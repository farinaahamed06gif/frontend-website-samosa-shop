# The Samosa Atelier — 3D Artisanal Samosa Experience
[Click here to visit my website](https://frontend-website-samosa-shop.vercel.app/)

A high-performance, frontend-only WebGL 3D showcase for an artisanal samosa atelier. Built with React 18, Three.js, and Tailwind CSS.

## Features

- **Interactive 3D WebGL Samosa**:
  - Parametric puffed equilateral tetrahedral geometry with realistic pinched seam pleating.
  - Procedural crust textures with blister gradients, ajwain flecks, and bump-mapped crisp lamination.
  - Real-time 60 FPS convection steam particle physics.
  - 4 interactive viewport modes:
    - **Atelier Crust**: Golden-brown fried pastry with specular highlights.
    - **Core Anatomy**: Translucent cutaway revealing spiced heirloom potatoes, garden peas, and whole coriander seeds.
    - **Thermal 180°C**: Thermodynamic false-color gradient mapping heat distribution across the frying envelope.
    - **CAD Wireframe**: Dihedral angles, golden ratio proportions, and pastry wall thickness metrics.
- **Acoustic Shatter Synthesizer**: Web Audio API procedural sound engine modeling 64 dB pastry shatter at 2.2 kHz – 4.8 kHz without external audio dependencies.
- **Flavour Matrix**: 4 signature formulations with real-time 3D specimen synchronization.
- **Client-Side Tasting Order System**: Real-time batch builder and reservation queue.
- **Concierge & Contact Hub**: Direct email dispatch, physical atelier coordinates, phone concierge, and interactive transmission desk.

## Tech Stack

- **Framework**: React 18
- **3D Graphics Engine**: Three.js
- **Styling**: Tailwind CSS
- **Audio**: Web Audio API (procedural synthesis)
- **Icons**: Lucide React
- **Build Tool**: Vite

## Getting Started

### Prerequisites

Node.js (v18 or higher) and npm.

### Installation

```bash
npm install
```

### Development Server

```bash
npm run dev
```

### Production Build

```bash
npm run build
npm run preview
```
